## Repository Access & Commands

### 1. Clone Repository
```bash
git clone https://github.com/BappadittyaMondal/Equity_Lab.git
```

### 2. Add as Git Submodule
```bash
git submodule add https://github.com/BappadittyaMondal/Equity_Lab.git path/to/subdir
```

### 3. Install via Pip directly from GitHub
```bash
pip install git+https://github.com/BappadittyaMondal/Equity_Lab.git
```
