## Government Policy Layer (Cross-Check for Any Sector Above)

When analyzing any sector in this table, check applicability of: Union Budget allocation, PLI schemes, Make in India / Atmanirbhar Bharat, National Infrastructure Pipeline, PM Gati Shakti, Digital India, Import duty/export incentive changes, Environmental regulations, State-specific incentives.

## Global Macro Layer (Cross-Check for Any Sector Above)

Route through `Domain_44_Geo_Economic_Impact.md` — it already maps USD/INR, crude oil, interest rates, FII/DII flow, and global growth to sector-specific effects. Don't re-derive these here; reference that domain.

## AI Decision Rule

1. Identify the company's primary sector from this table (or the 9 standalone-file sectors).
2. Apply that row's Key Metrics and Red Flags — don't apply a generic checklist to a sector-specific business.
3. Cross-reference Domain 25 for any macro-sensitive metric (fuel cost, currency exposure, rate sensitivity).
4. If a company spans two sectors (e.g., Auto + EV Ecosystem), apply both rows and note where they reinforce or conflict.
