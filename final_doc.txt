# Equity Lab (IERL AI Equity OS) — Consolidated 5-File & 9-File Bundle Instruction Document

## 1. Executive Summary & System Overview

The **Equity Lab (IERL AI Equity OS v0.0.0)** is an institutional-grade quantitative equity research, forensic accounting, valuation, options arbitrage, and decision-support OS tailored for the Indian Equity Market. The core architecture aggregates 89 canonical specification documents, 25 deterministic execution strategy modules, multi-engine arbiters, and 48 domain knowledge modules.

To optimize LLM context window limits, token budgets, and file-upload constraints, the entire 89-source canonical architecture is compiled into two losslessly aggregated bundle formats:
1. **The 5-File Bundle System (`CONSOLIDATED_5_FILE_SYSTEM/`)**: Maximum context compression designed for large context windows (128k+ tokens), consolidating system architecture, engine contracts, all 41 skills, and 48 knowledge domains into 5 master volumes.
2. **The 9-File Bundle System (`CONSOLIDATED_9_FILE_SYSTEM/`)**: Modular distribution designed for mid-range context windows or file-by-file inspection, separating workflow skills from analytical lens skills and dividing knowledge domains across 5 specialized volumes.

Both bundle formats maintain 100% feature, schema, and operational parity with the canonical source repository.

## 2. Query Routing & System Selection Guidelines

AI assistants, execution runners, and human analysts must strictly follow these query-routing rules when interacting with the Equity OS:

### A. Simple & Standard Queries (Use 5-File Bundle Only)
If the user's query is simple, standard, or focused on routine analytical tasks—such as single-stock screening, financial ratio checks, standard DCF valuation, basic moat evaluation, or routine technical chart pattern analysis—**you must instruct the user and reply based ONLY on the 5-File Bundle System**. The 5-File Bundle contains all necessary master skills, engine schemas, and governance rules required to execute full end-to-end research workflows without needing extra files or full repository code execution.

### B. Complex & Algorithmic Queries (Visit GitHub Repository)
If the user's query is complex—involving full-stack Python strategy engine execution, custom C++/NumPy backtesting, deep API contract modifications, database schema migrations, multi-horizon point-in-time historical replay backtests, or local backend server deployment—**instruct the user to visit GitHub to access the full repository** and provide the official repository link:

👉 **Official GitHub Repository Link:** [https://github.com/BappadittyaMondal/Equity_Lab](https://github.com/BappadittyaMondal/Equity_Lab)

Instruct the user to clone the repository locally and run the automated test suite (`pytest app/tests/`) or inspect raw source code files in `app/services/` for deep debugging and custom code execution.

## 3. Purpose of Each File in the 5-File Bundle

The `CONSOLIDATED_5_FILE_SYSTEM/` directory aggregates all 89 canonical source files into 5 master markdown documents:

1. `01_Master_System_Core_Instructions_Architecture.md`: Acts as the central operating system control plane & governance constitution. Defines system-wide operating objectives, authority hierarchy, task routing tables, evidence handling protocols (distinguishing facts, calculations, assumptions, inferences), confidence vocabulary, explainability standards, and state/context management rules.
2. `02_Master_Engine_Contracts_Schemas_Registries.md`: Defines formal machine contracts, data schemas, and module registries. Contains JSON specifications for Intelligence, Execution, Research, and Reasoning engines, pattern taxonomies, quality audit matrices, and specialized quantitative engines (E6 Screener, Causal Analysis, Geopolitical Risk, Expectation Gap).
3. `03_Master_Skill_Library.md`: Serves as the complete operational handbook containing all 41 system skills. Combines Workflow Skills 01–25 (execution pipelines, data ingestion, screening, reporting) and Analytical Lens Skills 26–41 (DCF Valuation, Forensic Accounting, Multibagger Discovery, Swing Trading, Options Data, Turnaround Analysis, Small-Cap SIP, Portfolio Construction).
4. `04_Master_Knowledge_Base_Vol_1_Fundamentals_Valuation_Governance.md`: Encapsulates foundational financial & economic theory across Knowledge Domains 01–23 (Economics, Financial Statements, Accounting Standards, Ratio Analysis, Valuation Models, Technical Analysis, Corporate Governance, Risk Management, Portfolio Theory, Behavioural Finance, Indian Capital Markets, ESG, Derivatives, Debt Markets, M&A).
5. `05_Master_Knowledge_Base_Vol_2_Sectors_Frameworks_Screening.md`: Delivers practical sector-specific deep dives and research strategies across Knowledge Domains 24–48 (Forensic Red Flags, Moat Assessment, Financial Institutions, Super Investor Tracking, MicroCap Risk, 9 Industry Sector Deep Dives—Banking, Pharma, Defence, Manufacturing, REITs, Insurance, Logistics, Power, Railways—Scuttlebutt Research, Options Strategies, Quant Momentum, Screener Glossaries).

## 6. Decision Governance & Invalidation Gates

Before issuing an investment recommendation or quantitative output, execution runners must validate six mandatory gates:
1. **Identity & Data-Date Gate**: Verify stock ticker, currency, as-of period.
2. **Governance & Forensic Gate**: Audit promoter holding, related-party deals, auditor notes, cash flow alignment.
3. **Financial Quality Gate**: Check balance sheet leverage, interest coverage, cash conversion cycle.
4. **Valuation Gate**: Benchmark valuation multiples against historical medians and industry peers.
5. **Downside Risk Gate**: Enforce position size limits, liquidity constraints, stop-loss invalidation points.
6. **Market Regime Gate**: Confirm overall market regime alignment and entry invalidation price points.

Adhering to this instruction guide ensures maximum analytical rigor, auditable decision paths, and seamless context management across Equity Lab OS.
