## Global Conflict Arbitration (when domains disagree)
1. **Forensic red flags (24) and Governance red flags (8)** override everything — integrity/fraud risk is a hard gate, not a weighted factor.
2. **Liquidity/surveillance status (29)** overrides conviction when sizing any micro/small-cap position.
3. **Cash-based evidence** (Domain 2 CFO, Domain 41 FCF payout) outranks accrual profit or narrative.
4. **Fundamentals (6, 25, 28)** govern the investment thesis; **Technicals (7, 30)/Derivatives (19)** govern only entry/exit timing.
5. **Pre-defined risk rules (43)** override in-the-moment conviction or emotional attachment (Domain 11 bias check).
6. **Live/current data** always outranks this library's static reference content.
7. **Primary sources** (Domain 17 hierarchy) outrank secondary summaries, screens, scuttlebutt (42), or management commentary.

## Recommended Workflow for This Trading Style
```
Screening (40) → Forensic + Governance Gate (24, 8) → Fundamental Deep-Dive
    (6, 25, 12/31-39 sector-specific) → Smart Money Check (27) →
    Technical Entry Timing (30) → Position Sizing & Rules (43, 29) →
    Ongoing Monitoring (Scuttlebutt 42, Risk 9) → Exit Discipline (43)
```

## Universal Rules (apply across all 44 domains)
- Evidence overrides assumptions; current data overrides historical/stored knowledge.
- Never invent or fabricate data/figures.
- Always disclose uncertainty when information is incomplete.
- Explain concepts simply before using advanced terminology.
- Distinguish facts from interpretations.
- Forensic/Governance screens are mandatory gates for every stock idea in this library's intended use case — never optional.
