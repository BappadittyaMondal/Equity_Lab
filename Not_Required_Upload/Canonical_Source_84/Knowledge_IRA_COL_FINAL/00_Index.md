## Global Conflict Arbitration (when domains disagree)
1. **Forensic red flags (24) and Governance red flags (8)** override everything — integrity/fraud risk is a hard gate, not a weighted factor.
2. **Liquidity/surveillance status (29)** overrides conviction when sizing any micro/small-cap position.
3. **Saatvik Ethical Filter (48)** overrides candidate selection prior to financial evaluation if sin categories are present.
4. **Cash-based evidence** (Domain 2 CFO, Domain 41 FCF payout) outranks accrual profit or narrative.
5. **Fundamentals (6, 25, 28, 47)** govern the investment thesis; **Technicals (7, 30, 46)/Derivatives (19, 45)** govern entry/exit timing & options execution.
6. **Pre-defined risk rules (43, 48/17 Position Sizing)** override in-the-moment conviction or emotional attachment (Domain 11 bias check).
7. **Live/current data** always outranks this library's static reference content.
8. **Primary sources** (Domain 17 hierarchy) outrank secondary summaries, screens, scuttlebutt (42), or management commentary.

## Recommended Workflow for This Trading Style
```
Saatvik Exclusion Filter (48) → Screening (40, 48) → Forensic + Governance Gate (24, 8) → 
    Fundamental/Value Deep-Dive (6, 25, 47) → Expert Lens Application (Domains 45-48 / 18 Strategies) → 
    Technical Entry Timing (30, 46) → Position Sizing & Pre-Decided Exits (43, 48/17) → 
    Ongoing Monitoring & Exit Discipline (43, 48)
```

## Universal Rules (apply across all 48 domains)
- Evidence overrides assumptions; current data overrides historical/stored knowledge.
- Never invent or fabricate data/figures.
- Always disclose uncertainty when information is incomplete.
- Explain concepts simply before using advanced terminology.
- Distinguish facts from interpretations.
- Forensic/Governance screens are mandatory gates for every stock idea in this library's intended use case — never optional.
